One emoji for a dream vacation: 🗻 — Mount Fuji at dawn, the trip of a lifetime, in a single glyph. A snow-capped mountain, a faraway place, a postcard with no words.

## Run it

```sh
node main.ts
```

Writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`), self-checking the kit's 1–8 character gate and the exactly-one-emoji rule.
